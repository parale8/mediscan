# MediScan AI — Spandan Clinical AI

Medical report analyser. Photograph or upload reports; get a structured Doctor
Report, a Patient Summary in English / मराठी / ಕನ್ನಡ / हिन्दी, and a Clinical Story.

Developed by Dr Gurunath Parale
Spandan Cardiac Diagnostic and Research Centre, Solapur

## Setup

No API key is stored in this repository. On first use, open **API Configuration**
at the top of the app, paste your Google Gemini API key, and press **Save Key**.
The key is stored only in that browser and is never uploaded anywhere.

Get a key at https://aistudio.google.com/apikey

## Files

- `index.html` — the whole application
- `bridge.js` — lets the OneGlance MediScan Bridge Chrome extension drive the app
